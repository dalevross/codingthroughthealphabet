# G — Go

**Language:** Go  
**File:** `fibonacci.go`

Go (also known as Golang) is an open-source programming language created by Google. It is statically typed, compiled, and designed for simplicity and efficiency.

**Prerequisites:** Go

- Ubuntu/Debian: `sudo apt install golang-go`
